# Brood benchmarks — against eight other languages

31 programs under one harness, measuring Brood's startup, memory, compute and concurrency
against mature runtimes: a snapshot of where it stands, not a claim to lead. **C** is a
machine-floor reference for 16 compute rows, not a peer ([why](bench/c/README.md)). **Go** sits
between C and .NET and runs every managed row ([notes](bench/go/README.md)).

## Running it

```sh
nest run -- harness                               # full suite, best of 3 → results/
nest run -- harness --only fib --langs brood,c    # a subset
nest run -- chart && nest run -- trend && nest run -- docs
```

Sources are in [`bench/`](bench/), named identically per language (`fib.blsp`, `fib.c`, …) so
they diff side by side; `BENCH_N=35 brood bench/brood/fib.blsp` runs one standalone. Every
program prints one checksum and the harness fails the run if the columns disagree. Rankings use
**compute = wall − that language's `startup`**.
